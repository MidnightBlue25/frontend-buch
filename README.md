# Frontend Book – Web Application

Frontend application built with Next.js and TypeScript, focusing on modern web development, UI structure, and automated testing.

## Technologies
- Next.js
- React
- TypeScript
- CSS
- Playwright (End-to-End Testing)

## Features
- Development of a modern web application using Next.js
- Structured UI and component architecture
- Page-based routing and application logic
- End-to-end testing with Playwright

```bash
npm install
npm run dev
